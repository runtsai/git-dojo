# Code of Conduct

## Our commitment

We want Git Dojo to be a welcoming place to learn, ask questions, and contribute. Everyone participating in this project is expected to treat others with respect.

## Expected behavior

- Use welcoming, clear language.
- Assume good intent and give helpful feedback.
- Respect different levels of experience.
- Focus criticism on ideas and changes, not people.
- Accept responsibility when a mistake is made and help correct it.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or imagery in project spaces.
- Publishing someone else’s private information.
- Deliberately disruptive behavior or bad-faith contributions.
- Dismissing or mocking beginner questions.

## Reporting

If you experience or witness unacceptable behavior, contact the repository maintainer privately through the [GitHub repository](https://github.com/runtsai/git-dojo). Do not use a public issue for sensitive reports.

The maintainer will review reports promptly and may remove content, limit participation, or take other appropriate action.

## Scope

This policy applies in Git Dojo repository spaces and in interactions where someone represents the project.
