# Security Policy

## Supported versions

Security fixes are made against the current `main` branch and the live Git Dojo deployment.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a suspected security problem.

Instead:

1. Use GitHub’s private vulnerability-reporting option for this repository when it is available, or
2. Contact the repository maintainer privately through [github.com/runtsai](https://github.com/runtsai).

Please include:

- A clear description of the issue.
- Steps to reproduce it.
- The potential impact.
- Any suggested mitigation, if you have one.

You will receive an acknowledgement as soon as practical. Please give the maintainer reasonable time to investigate and release a fix before discussing the issue publicly.

## Scope

Reports are especially helpful for issues involving:

- Unauthorized access to learner progress or lesson data.
- Exposure of secrets or private files.
- Unsafe filesystem or Git operations.
- Injection, cross-site scripting, or denial-of-service risks.
- Dependency vulnerabilities affecting the deployed application.
