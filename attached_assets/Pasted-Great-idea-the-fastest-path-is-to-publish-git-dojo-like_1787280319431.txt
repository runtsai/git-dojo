## 2) Clarify “GitHub Learning Marketplace”
There isn’t a single official “GitHub Learning Marketplace” for listing arbitrary open-source apps like an app store.  
For GitHub ecosystem visibility, people usually use:
- **GitHub Marketplace** (mainly for GitHub Apps/Actions integrations)
- **Awesome lists**, community showcases, dev forums, Product Hunt, Reddit, Hacker News, etc.

If `git-dojo` is a standalone learning app, focus on open-source channels first.  
If it’s a **GitHub Action/App**, then Marketplace can make sense.
